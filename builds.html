Semantic Editing
04

AI Audio Auditor

Contextual audio editing that asks "does this sound natural to a human listener?" — not "is the timestamp technically correct?" Whisper transcription → word-level timestamps → VAD segmentation → Gemma semantic analysis → editorial validation → correction.

5-Pass Validation
Pass 1: Word-level transcription precision.
Pass 2+3: Deep-scan analysis + DSP boundary validation across 8 categories.
Pass 4: QC audit before execution — catches over-cutting, meaning loss, flow breaks.
Pass 5: Execute confirmed cuts only.
Script Engineering
05

Script Director

Multi-mode scripting system with a proprietary kinetic notation — [Archetype, Intensity, Stage] ((Kinetic Actions)) — that engineers vocal performance at the instruction level. The engine interprets these into acoustic behavior.

Modes & Notation
Modes: Podcast, News, General, Cinematic Audiobooks.
Kinetic Notation: [Cynic, i4, S5] ((labored breath)) — i4 = specific glottal tension, S5 = high breath-to-voice ratio.
Capabilities: Generate from context, optimize existing, add vocal cues, isolate speaker scripts, TTS performance notes.

Architecture

Voice: Zephyr + full kinetic notation [Archetype, Intensity, Stage].
Output: 48,000 Hz · 24-bit PCM WAV.
Voice Science
07

Maya LoRA — Voice Lab

Acoustic fingerprinting system that extracts F0 pitch, RMS energy, spectral brightness, and 13 MFCCs from any recording — then scores voice consistency 0–100 via cosine similarity. The measurement system that defines what voice consistency means numerically.

4-Step Pipeline
Step 1: Reference audio generation (voice instruct → .wav).
Step 2: Acoustic feature extraction via librosa — F0, RMS, Tempo, Spectral Brightness, 13 MFCCs.
Step 3: Locked audio generation using instruct string.
Step 4: Voice similarity scoring — ≥75 locked, 50–74 partial, <50 rework.
