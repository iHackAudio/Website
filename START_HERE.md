## 🎯 What You Need to Do

### Step 1: Get the FULL Project

**Option A - Download ZIP (Easiest):**
1. Go to https://github.com/akashrmalhotra/3d-portfolio
2. Click green **"<> Code"** button
3. Click **"Download ZIP"**
4. Extract the ZIP file on your computer

**Option B - Use Git:**
```bash
git clone https://github.com/akashrmalhotra/3d-portfolio.git
```

### Step 3: Install & Build

Open Terminal/Command Prompt in the project folder:

```bash

npm install

# Build the project
npm run build
```

---

### Step 4: Deploy

**Netlify (Recommended - No size limit):**
1. Go to https://app.netlify.com/drop
2. Drag the `dist/` folder onto the page
3. Your site is live!

**Vercel:**
1. Push to GitHub
2. Connect to https://vercel.com
3. Auto-deploy!

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| "npm not found" | Install Node.js from https://nodejs.org |
| "Cannot find module" | Run `npm install` again |
| Build fails | Delete `node_modules`, then `npm install` |
| 3D character missing | Check `public/models/` folder exists |
| Site blank | Check browser console (F12) for errors |
